# react-timeline-editor 接入后的产品预期

## 1. 产品定位

接入 `@xzdarcy/react-timeline-editor` 后，goclip 将从“通过对话生成剪辑结果”升级为：

> 对话式剪辑 + 可视化时间线编辑 + 证据辅助决策的一体化视频工作台。

用户既可以用自然语言指挥 Agent，也可以直接在时间线上查看、调整和确认剪辑结果。

时间线组件负责交互和可视化，视频理解、证据分析、时间线数据、版本控制和 FFmpeg 渲染仍由 goclip 自己负责。

## 2. 用户看到的界面

工作区以“视频预览 + Agent 对话 + 时间线编辑器”为核心布局：

- 视频预览窗口
- Agent 对话区
- 可缩放的多段视频时间线
- 当前播放指针
- 片段名称、来源时间和实际时长
- 倍速、静音和字幕状态
- 语音、镜头、停顿、响度和高光等辅助轨道
- 渲染、导出和版本操作入口

时间线中的片段来自现有的 `timeline_segments` 数据，不额外维护一套独立剪辑状态。对话修改、手动拖动和最终渲染始终基于同一份时间线。

## 3. 用户可以如何使用

用户可以直接对 Agent 说：

> 把第二段缩短 3 秒

> 把开场放到最后

> 第三段改成 1.5 倍速

> 删除所有明显停顿

> 字幕改成黄色粗体，底部居中，黑色描边

> 把这几个高光片段拼成 60 秒

Agent 修改后，时间线立即反映新的片段顺序、时长和播放设置。用户也可以直接拖动片段边界、调整片段顺序或修改倍速。

## 4. 对话和时间线的协作方式

```text
用户自然语言
    ↓
Agent 理解剪辑意图
    ↓
生成或修改时间线方案
    ↓
时间线界面即时展示
    ↓
用户继续对话或手动微调
    ↓
用户确认
    ↓
调用 FFmpeg 渲染成片
```

例如用户说：

> 把 30 秒到 45 秒这段换成原视频 182 秒到 197 秒的片段

Agent 完成修改后，时间线上会直接显示替换后的片段。用户能够看到片段长度、来源区间和最终顺序，而不是只能阅读工具返回的 JSON。

## 5. 时间线编辑能力

接入后的时间线应支持以下操作：

### 片段操作

- 拖动片段改变顺序
- 拖动左右边界进行裁剪
- 添加新的素材片段
- 删除片段
- 拆分片段
- 合并相邻片段
- 修改片段名称或标记

### 播放设置

- 调整播放速度
- 静音或恢复声音
- 显示源素材区间
- 显示变速后的实际成片时长

### 播放联动

- 点击片段跳转到对应视频位置
- 拖动播放指针预览当前画面
- 播放时指针跟随视频移动
- 从证据标记跳转到原始素材位置

## 6. 证据辅助剪辑

时间线不仅显示视频片段，还应显示视频理解结果形成的证据轨道：

- 语音转写
- 屏幕文字
- 镜头切点
- 停顿区间
- 响度变化
- 画面描述
- 章节信息
- AI 标记的高光片段

用户可以直观看到某个片段为什么被选中，例如：

- 这一段包含目标原话
- 这一段是高光内容
- 这一段的响度明显升高
- 这一段镜头节奏更快
- 这一段没有明显停顿

这样 Agent 的剪辑建议可以被核对，而不是变成无法解释的黑盒结果。

## 7. 自然语言控制字幕样式

字幕样式可以通过自然语言描述，Agent 将其转换为结构化样式参数。

例如：

> 字幕改成黄色粗体，黑色描边，底部居中，加半透明黑底

对应的样式效果包括：

- 字体和字号
- 正常或粗体
- 文字颜色
- 描边颜色和宽度
- 九宫格位置
- 背景颜色和透明度
- 阴影颜色、模糊和偏移

字幕可以选择：

- 只导出为 SRT 或 WebVTT
- 作为预览轨道显示
- 直接烧录进成片

字幕时间使用成片坐标，因此在片段被裁剪、重排或变速后仍能和画面保持一致。

## 8. 修改安全性和版本控制

所有时间线修改继续使用现有 revision 机制：

- 每次编辑都携带 `base_revision`
- 版本冲突时拒绝覆盖旧数据
- 前端重新读取最新时间线后再应用修改
- 每次编辑保留历史版本
- 用户可以回滚到之前的 revision
- 渲染前可以确认当前最终时间线

这保证了手动编辑、Agent 编辑和多窗口操作不会互相静默覆盖。

## 9. 渲染结果

用户确认时间线后，Agent 调用现有渲染能力生成成片：

- 按时间线顺序拼接片段
- 正确处理裁剪和关键帧
- 正确处理倍速后的音视频同步
- 应用画幅和重构图设置
- 烧录字幕或导出字幕文件
- 上传成片并返回本地路径和 OSS 地址
- 返回实际成片时长、片段数量、重编码状态和处理阶段

渲染失败时，界面应展示具体失败阶段，例如：

- 下载素材失败
- 切割片段失败
- 拼接失败
- 字幕烧录失败
- 上传成片失败

## 10. 产品边界

接入该组件后，产品的核心优势是“理解视频并协助剪辑”，不是立即成为完整的专业非线性编辑软件。

以下能力仍属于后续增强方向：

- 专业级多轨音频混音
- 复杂转场编辑
- 关键帧动画
- 高级调色
- 特效节点编排
- 大规模素材管理

时间线组件本身是通用 React 时间线编辑器，负责片段交互和轨道展示；视频缩略图、音频波形、证据数据和渲染能力需要接入 goclip 现有后端能力。

## 11. 最终用户体验

最终用户不需要在“聊天工具”和“剪辑软件”之间来回切换：

- 想法可以直接用自然语言表达
- Agent 可以解释剪辑依据
- 时间线可以实时核对和手动微调
- 证据可以回跳到视频原始位置
- 修改过程有版本保护
- 结果可以直接预览、导出和回滚

产品最终呈现的是一个可理解、可确认、可调整的智能剪辑工作台。
