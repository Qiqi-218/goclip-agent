# 产品需求

## 定位

Video Agent 是本机运行的长视频理解与智能剪辑助手。Web 是创作者的主入口；CLI/API 是内部实现、调试和回归入口，不要求用户理解或直接使用。

## 首期用户旅程

1. 创建项目，通过文件选择或拖放导入 1–10 段视频，可选加入 SRT/VTT。
2. 分析视频，获得带源时间范围的字幕、ASR 或代表帧证据；未配置模型时明确引导而不编造结果。
3. 输入自然语言目标，例如“保留 AI 解题的结论，剪成一分钟”。
4. 审阅候选片段、来源、时长与剪辑摘要；确认前不修改工程。
5. 确认方案，生成预览；满意后导出真实 MP4 并下载。

## 当前范围

- 总素材时长暂限约 30 分钟；支持本地 MP4、MOV、M4V。
- 证据包括带时间戳的字幕/转写和代表帧；可选接入文本、视觉和 ASR provider。
- 支持主题选片、目标时长和方案确认；所有候选必须可追溯。
- 使用版本化时间线、异步渲染和完整解码校验保证出片可靠。
- 本机与 Docker/Windows 均可运行；模型密钥只来自本地环境变量。

## 下一阶段

- 对话式局部编辑：替换、删除、缩短、重排、撤销和恢复的普通用户界面。
- 语义质量：场景切分、embedding、重复片段过滤、节奏/情绪评分与更精确的句级选段。
- 成片增强：字幕渲染、BGM/混音、9:16 fit/crop 和基础构图。
- 可靠性：服务重启后的任务恢复、重试、临时文件回收和工程迁移。

## 不在范围

生成式视频、自动发布、账号/计费、多人实时协作、模板/贴纸商城、复杂多机位、专业调色、复杂动画与任意脚本执行。

## 验收

- 用户不填写路径、ID 或 JSON 即可完成完整 Web 闭环。
- 每个候选与成片片段都有素材 ID、源时间范围和 Evidence 来源。
- 无字幕/无模型、无匹配、模型错误与渲染失败均给出可行动的提示，不创建虚构片段。
- 导出通过分辨率、帧数、时长、编码和完整解码验证。
- 在真实长视频任务上，用户能审阅并确认方案，而不是依赖不可解释的自动剪辑。
