# 产品定义

## 一句话定义

Video Agent 是一个能听懂人话的长视频理解与智能剪辑助手：它把长视频解析成多维、可检索、可追溯的证据，让创作者用自然语言精确控制剪辑结果。

## 产品闭环

```text
长视频 / 字幕
      ↓ 导入与分析
带时间范围的证据：转写、画面、元数据
      ↓ 自然语言请求
候选片段与可审阅剪辑方案
      ↓ 用户确认
时间线、预览、验证后的 MP4
```

自然语言是主入口，不是模型绕过剪辑规则的后门：候选必须来自证据，修改必须经过确认，导出必须通过媒体校验。

## 目标用户与问题

目标用户是需要从访谈、口播、课程、直播回放、活动记录等长视频中提炼内容的个人创作者。他们想表达的是“保留论文结论，剪成一分钟”“删掉开场”“第二段再短一点”，而不是素材 ID、帧率和 JSON。

传统剪辑器的时间线适合逐帧手工操作，却不擅长回答“视频里哪里讲了这个”。通用聊天模型又容易给出不能核对的时间戳。Video Agent 的工作是把理解与执行之间建立一条可追溯的桥：先找证据，再提出方案，再可靠地生成成片。

## 核心能力

1. **长视频理解**：导入本地视频，结合 SRT/VTT、ASR、代表帧和视觉描述，生成带源时间范围的 Evidence。
2. **多维检索**：按转写文本、主题与画面描述查找候选，结果始终显示来源与时间。
3. **自然语言控制**：理解主题选片、目标时长与常见局部修改意图；素材不足时明确返回无匹配或要求补充信息。
4. **可控剪辑**：先展示剪辑方案，用户确认后才创建或更新时间线；revision、撤销与来源关系保证局部修改不会失控。
5. **真实出片**：预览与导出通过 FFmpeg、元数据和完整解码校验后才算完成。

## 当前产品边界

当前 Web 已支持项目创建、文件选择/拖放导入、可选字幕导入、分析、主题选片方案、确认、预览和 MP4 导出。底层 CLI、JSON 工具和 loopback HTTP API 仍保留给实现、调试与自动化回归，但不再是产品主入口。

首期不做模板/贴纸生态、生成式视频、自动发布、账号计费、多人协作、复杂调色、多机位和专业动画。字幕渲染、BGM、9:16 构图，以及更丰富的局部对话编辑是下一阶段能力，而不是当前承诺。

## 模型与隐私

项目、素材和渲染产物保存于本机。没有模型配置时，用户可导入字幕完成可追溯选片；配置 ASR、文本或视觉 provider 后，服务端会将所需的音频片段、文本或代表帧发送给该 provider。密钥只读取本地环境变量，绝不进入浏览器、数据库、日志或 Git。

## 成功标准

一位创作者无需输入路径、素材 ID 或 JSON，即可完成：导入长视频 → 分析 → 用自然语言得到有来源的选片方案 → 确认 → 预览 → 导出。成片中的每一段都可追溯到原始素材与时间范围。
